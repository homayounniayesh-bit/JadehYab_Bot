# 🛣️ RoadRadar Bot

یک بات تلگرام برای پیدا کردن **وضعیت جادهها** در مسیرهای شمال ایران:
ترافیک 🚗، تصادف 🚨، بستهشدن مسیر 🚧 و شرایط نامناسب ⛈️.

بات **خودش وب را جستجو میکند** (از Google News و Bing News RSS) و نیازی به کلید API ندارد.
اگر اینترنت در دسترس نباشد، یک وضعیت نمونه ذخیرهشده نشان میدهد.

## قابلیتها

- انتخاب گامبهگام: **استان → شهر → جاده/خیابان** با دکمههای شیشهای
- جستجوی آزاد با تایپ: `مازندران / چالوس / جاده چالوس` یا `ترافیک جاده هراز امروز`
- دستور سریع: `/search جاده چالوس ترافیک`
- دستهبندی خودروی اخبار به ۴ گروه ترافیک / تصادف / بستهشدن / شرایط نامناسب
- نمایش منبع، زمان انتشار و لینک خبر
- دکمه «بروزرسانی همین مسیر»
- پوشش ۸ استان شمالی: گیلان، مازندران، گلستان، سمنان، قزوین، البرز، تهران، اردبیل

## نصب و اجرا

### ۱. ساخت بات و گرفتن توکن
1. در تلگرام به [@BotFather](https://t.me/BotFather) بروید.
2. دستور `/newbot` را بزنید و نام بات و username آن را مشخص کنید.
3. توکنی که به شما میدهد را نگه دارید.

### ۲. نصب وابستگیها
```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

### ۳. تنظیم توکن
```powershell
Copy-Item .env.example .env
```
سپس فایل `.env` را باز کنید و `BOT_TOKEN` را با توکن خود جایگزین کنید.

### ۴. اجرا
```powershell
python run.py
```

## دستورات بات

| دستور | کار |
| --- | --- |
| `/start` | شروع و منوی اصلی |
| `/status` | بررسی وضعیت جاده (گام به گام) |
| `/search <عبارت>` | جستجوی سریع |
| `/help` | راهنما |
| `/cancel` | لغو عملیات فعلی |

## ساختار پروژه

```
bot/
├── main.py              # نقطه ورود و راهاندازی aiogram
├── config.py            # خواندن تنظیمات از .env
├── data/roads.py        # لیست استان/شهر/جاده + تطبیق متن آزاد
├── keyboards/inline.py  # دکمهها و callback data
├── handlers/
│   ├── commands.py      # دستورات /start, /search, ...
│   ├── flow.py          # جریان FSM و متن آزاد
│   └── searcher.py      # ارسال نتیجه جستجو
└── services/
    ├── search.py        # جستجو در Google News / Bing News + Fallback
    └── formatter.py     # ساخت پیام فارسی و دستهبندیها
```

## شخصیسازی

- **افزودن شهر یا جاده:** فایل `bot/data/roads.py` را ویرایش کنید و به لیست `PROVINCES` اضافه کنید.
- **تغییر تعداد نتایج:** `MAX_RESULTS` در `.env`.
- **تغییر منابع جستجو:** توابع `_fetch_google` و `_fetch_bing` در `bot/services/search.py`.
- **ذخیره موقت پیشرفته:** فعلاً از `MemoryStorage` استفاده شده؛ برای Production میتوانید از
  `aiogram.fsm.storage.redis.RedisStorage` استفاده کنید.

## اجرا در پسزمینه

**اندروید (Termux):**
```bash
pkg install tmux -y
chmod +x run_background.sh
./run_background.sh
```
دیدن لاگ: `tmux attach -t roadradar` · خروج بدون متوقف کردن: `Ctrl+b` سپس `d` ·
متوقف کردن: `tmux kill-session -t roadradar`

**ویندوز:**
روی `run_background.vbs` دوبار کلیک کنید. بات بدون پنجره اجرا میشود و لاگ در
`logs\bot.log` ذخیره میگردد. برای اجرا خودکار موقع روشن شدن ویندوز، میانبری از
این فایل داخل پوشه `Startup` بذارید.

> توجه: اجرا در پسزمینه گوشی ممکن است توسط سیستم اندروید متوقف شود. برای آنلاین
> ماندن دائمی از هاست ابری (Render / Replit) استفاده کنید.

## همیشه آنلاین (هاست رایگان Render)

بات یک سرور ساده `/health` هم دارد تا روی هاستهای رایگان بیدار بماند.

1. یک مخزن GitHub بسازید و **همه فایلها بهجز `.env`** را آپلود کنید.
2. در [render.com](https://render.com) وارد شوید → **New + → Blueprint** → مخزن GitHub را وصل کنید.
3. Render فایل `render.yaml` را پیدا میکند → **Apply** بزنید.
4. در بخش **Environment** مقدار `BOT_TOKEN` را با توکن بات پر کنید.
5. بعد از deploy، آدرسی مثل `https://roadradar-bot.onrender.com` میگیرید.
6. **مهم:** پلن رایگان Render بعد از ۱۵ دقیقه بیکاری میخوابد. در
   [cron-job.org](https://cron-job.org) (رایگان) یک job بسازید که هر **۵ دقیقه**
   آدرس `https://roadradar-bot.onrender.com/health` را بزند تا بات همیشه بیدار بماند.
7. در تلگرام به باتتان `/start` بفرستید — حتی اگر گوشی و کامپیوترتان خاموش باشد کار میکند.
